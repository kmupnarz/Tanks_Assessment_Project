# Tanks Assessment Project

A structured assessment project focused on technical implementation and scripting workflows in game engines.

## 🚀 Project Overview
This project was built to demonstrate competency in asset integration, scene management, and game loop scripting. It features top-down tank mechanics and controlled combat systems.

## 🛠️ Features Implemented
* **Movement Logic:** Programmed top-down tank controls (tank steering and turret rotation).
* **Prefab Architecture:** Used reusable engine prefabs for projectiles and enemy spawning.
* **Scene Hierarchy:** Organized project folders and game objects into a clean, predictable hierarchy.

## 💻 Tech Stack
* **Language:** ShaderLab / C#
* **Engine:** Unity
